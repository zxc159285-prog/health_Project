PROJECT 02 · 01 · DUAL AUTH & BCRYPT SECURITY
[기능 1] 이중화 회원가입 (`join`/`autoJoin`) & BCrypt 암호화 파이프라인 조종현 100% 전담

수동 가입과 계약서 자동 가입 이원화, 8자리 전화번호 전처리 및 `BCryptPasswordEncoder` 암호화 적용.

기능 설명 & 설계 의도
  • 이중화 가입 아키텍처: 일반 수동 회원가입과 계약서 발행 연동 자동 회원가입(`autoJoin`) 이원화 처리.
  • 전화번호 8자리 정규화: 입력받은 전화번호에서 `010` 등 상위 번호를 정제하여 8자리 정수(`formatUsernameToEightDigits`)로 통일.
  • BCrypt 해시 보안: 계정 정보 수정 API(`PUT /member/update`) 시 `BCryptPasswordEncoder`로 암호화 후 DB 반영.
실제 백엔드 소스코드 (MemberService.java)
@Autowired
private BCryptPasswordEncoder passwordEncoder;

public int update(MemberDTO memberDTO) throws Exception {
    if (memberDTO.getPassword() == null || memberDTO.getPassword().trim().isEmpty()) {
        return -1; 
    }
    if (!memberDTO.getPassword().equals(memberDTO.getPasswordCheck())) {
        return -2; // 비밀번호 불일치 에러 플래그
    }
    // BCrypt 평문 해시 암호문 치환
    String hashedPassword = passwordEncoder.encode(memberDTO.getPassword());
    memberDTO.setPassword(hashedPassword);

    return memberMapper.update(memberDTO);
}

실제 백엔드 소스코드 (CouponService.java)
@Transactional
public int sendCoupon(CouponDTO couponDTO) throws Exception {
    // 미사용 동일 쿠폰 보유 여부 중복 방어
    int dupCount = couponMapper.checkDuplicateUnused(
        couponDTO.getToId(), couponDTO.getCouponNum()
    );
    if (dupCount > 0) {
        throw new IllegalArgumentException("이미 미사용 동일 쿠폰을 보유 중입니다.");
    }
    int result = couponMapper.sendCoupon(couponDTO);
    if (result > 0) {
        couponMapper.sendCount(couponDTO.getCouponNum());
        alarmService.sendAlarm(
            couponDTO.getToId(), couponDTO.getFromId(),
            "새로운 쿠폰 도착: " + couponDTO.getCouponName(),
            "/fitc/mypage/coupon", "COUPON"
        );
    }
    return result;
}

기능 설명 & 설계 의도
  • SseEmitter 실시간 전선 객체: 30분 타임아웃 전선 객체를 메모리 저장소에 보관 후 비동기 이벤트를 즉시 푸시.
  • 503 Gateway Timeout 방어: 최초 구독 개설 시 `connect` 더미 이벤트를 즉시 전송하여 게이트웨이 만료 방지.
  • 경험 향상 & 자동 소거: 알림 클릭 시 해당 목적지 URL로 워프 이동 및 1개월 경과 구형 알림 주기적 자동 소거.
실제 백엔드 소스코드 (AlarmService.java)
private SseEmitter subscribe(String username) throws Exception {
    // 30분 만료 시간을 가진 새로운 실시간 전선 객체 생성
    SseEmitter emitter = new SseEmitter(DEFAULT_TIMEOUT);

    emitter.onCompletion(() -> alarmRepository.remove(username, emitter));
    emitter.onTimeout(() -> alarmRepository.remove(username, emitter));
    emitter.onError(e -> alarmRepository.remove(username, emitter));

    // 503 Gateway Timeout 방지 최초 핑 이벤트 전송
    emitter.send(SseEmitter.event().name("connect").data("연결 완료"));
    alarmRepository.save(username, emitter);
    return emitter;
}

// 최근 30일 범위 출석 필터링 & 자연 감량 세팅
const today = new Date();
const thirtyDaysAgo = new Date(today.getTime() - 30 * 24 * 60 * 60 * 1000);

const recentCheckins = data.filter(item => {
  if (!item.checkIn) return false;
  const checkinDate = new Date(item.checkIn);
  return checkinDate >= thirtyDaysAgo && checkinDate <= today;
});
